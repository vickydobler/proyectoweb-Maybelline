clean look

  1. hidratá y aplicá protector solar.
  2. usá una base ligera o tint para emparejar la piel.
  3. poné rubor en crema en mejillas y labios.
  4. peiná las cejas hacia arriba.
  5. aplicá gloss transparente. listo.
tutorial youtube

gala brillante

  1. prepará la piel con una prebase iluminadora.
  2. usá sombras con shimmer (brillo) en el párpado móvil.
  3. difuminá el color en la cuenca para profundidad.
  4. hacé delineado fino y aplicá máscara de pestañas.
  5. usá iluminador en pómulos y arco de cupido.
tutorial youtube

glam de noche

  1. aplicá base de cobertura media.
  2. usá sombras oscuras para un efecto ahumado.
  3. delineado intenso + pestañas postizas o mucha máscara.
  4. contorno suave y labio nude.
  5. cerrá con spray fijador para que dure toda la noche.
